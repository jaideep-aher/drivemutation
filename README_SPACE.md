Counterfactual AV test compiler. Compare stock GPT vs a fine-tuned OpenAI model.

- `OPENAI_API_KEY`
- `OPENAI_BASE_MODEL` (default `gpt-4o-mini-2024-07-18`)
- `OPENAI_FINE_TUNED_MODEL` (your `ft:...` id)
